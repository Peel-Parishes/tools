Installing it

  • Gmail (web): Settings ⚙ → See all settings → General → Signature → Create new. Paste, then Save changes at the bottom. Set it as default for new emails and replies.
  • Outlook (web / new Outlook): Settings → Accounts → Signatures → New signature. Paste and Save.
  • Apple Mail (Mac): Mail → Settings → Signatures. Add one, paste, and untick "Always match my default message font".
  • iPhone Mail: pasting rich signatures is unreliable. Email the signature to yourself from a computer, copy it from that email, and paste into Settings → Mail → Signature. Shake to undo if iOS strips formatting.
  • Test it: send one email to a Gmail address and one to an Outlook/Hotmail address before you rely on it.
